## 表3-1 可观测证据说明表

| 证据类型 | 符号 | 含义 | 来源 | 作用 |
|---|---|---|---|---|
| 模态可用性 | \(a_m(x)\) | 判断模态是否存在且可被模型使用 | PT样本字段与解析状态 | 缺失模态的可信评分置零 |
| 模态完整性 | \(q_m(x)\) | 描述静态解析证据的完整程度 | API、调用图和Manifest元数据 | 衡量样本级证据质量 |
| 模型可见比例 | \(v_m(x)\) | 描述编码器实际看到的信息比例 | 输入长度、节点预算和可见统计 | 修正长序列或大图预算带来的影响 |
| 有效完整性 | \(e_m(x)\) | 综合模态完整性和模型可见比例 | \(q_m(x)v_m(x)\) | 作为可见性修正依据 |
| 跨模态支持关系 | \(s_m(x)\) | 描述不同模态之间是否相互支持 | API-Graph对应关系、Manifest-Code关系 | 辅助判断模态证据是否可信 |
| 分支能力先验 | \(C_m\) | 描述分支在校准集上的整体判别能力 | 校准集分支性能统计 | 避免整体较弱的分支过度影响融合 |

## 表4-1 分支证据表示说明表

| 符号 | 含义 | 说明 |
|---|---|---|
| \(\omega_m\) | 模态 \(m\) 的证据表示 | 由类别支持度和不确定程度组成 |
| \(\mathbf{b}_m\) | 类别支持度向量 | 表示模态 \(m\) 对各类别的支持程度 |
| \(u_m\) | 不确定程度 | 表示该模态未能明确分配给具体类别的部分 |
| \(\widetilde{\omega}_m\) | 调整后的模态证据 | 由模态可信评分调整后得到 |
| \(\kappa\) | 多模态冲突程度 | 表示不同模态判断不一致的程度 |
| \(\omega^f\) | 融合后的证据表示 | 由三模态证据组合得到 |

## 表4-2 不同融合方式对比表

| 融合方式 | 是否使用模态可信度 | 是否表达不确定性 | 是否保留冲突信息 | 特点 |
|---|---|---|---|---|
| 特征拼接 | 否 | 否 | 否 | 实现简单，但难以解释各模态贡献 |
| 概率平均 | 否 | 否 | 否 | 易受低质量分支影响 |
| 固定加权融合 | 部分 | 否 | 否 | 权重固定，不能随样本变化 |
| Dempster组合 | 部分 | 是 | 弱 | 冲突可能被重新归一化到类别支持度中 |
| 本文方法 | 是 | 是 | 是 | 低可信证据被削弱，冲突部分转化为不确定性 |

## 表5-1 类别条件拒识符号说明表

| 符号 | 含义 | 说明 |
|---|---|---|
| \(p_c^f(x)\) | 融合后类别概率 | 样本 \(x\) 属于类别 \(c\) 的概率 |
| \(\kappa(x)\) | 原始模态冲突程度 | 来自第四章融合前的模态冲突 |
| \(r_c(x)\) | 预测不可靠程度 | 由类别概率不足和模态冲突共同决定 |
| \(\tau_c\) | 类别 \(c\) 的拒识阈值 | 在校准集上按类别确定 |
| \(A(x)\) | 接受指示变量 | 1表示接受预测，0表示拒识样本 |

## 表5-2 拒识评价指标说明表

| 指标 | 含义 | 作用 |
|---|---|---|
| 覆盖率 | 被模型接受预测的样本比例 | 衡量模型保留多少预测结果 |
| 接受样本风险 | 接受样本中的错误比例 | 衡量拒识后的预测可靠性 |
| 拒识后恶意漏报数 | 被接受样本中恶意误判为良性的数量 | 衡量安全检测中的漏报风险 |
| 类别覆盖率 | 分类别统计接受比例 | 检查良性与恶意样本是否被均衡处理 |
| 面积风险指标 | 不同覆盖率下风险曲线的平均水平 | 衡量排序式拒识能力 |
