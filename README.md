# CARE-Droid

This directory is the frozen CARE-Droid v1 experiment project. It reuses the
existing APK-derived PT payloads; the proposed method does not require
regenerating API or Graph tensors.

The current method is exactly:

```text
clean AGM/AG/AM/GM path experts
    -> three-fold group-OOF path-correctness estimation
    -> disagreement-aware AGM-anchored routing
    -> natural-distribution accepted-FN conformal risk control
```

## Frozen algorithm

1. **Clean four-path experts.** Shared API, Graph, and Manifest encoders feed
   four independent lightweight heads: AGM, AG, AM, and GM. Stage A minimizes
   the arithmetic mean of the four clean cross-entropies. Its checkpoint is
   selected only by clean AGM Macro-F1 on group-disjoint `expert_val`; exact
   ties keep the earliest epoch.
2. **Leakage-safe path correctness and bounded routing.** A shared 11-16-1 risk
   head estimates each fixed path's hard-prediction correctness from four
   fold-normalized path log-odds, three alive bits, and one candidate-path
   one-hot. It is trained with three group-disjoint OOF folds, fold-local
   valid-only normalization, fixed epochs, and deterministic controlled views.
   With all modalities alive, AGM remains the anchor and only a disagreeing
   pair with strictly higher predicted correctness can replace it.
3. **Natural accepted-FN CRC.** A disjoint natural-only `decision_cal` role fits
   the acceptance threshold. Malware predictions are always accepted; benign
   predictions are accepted by the selected path-correctness score. Equal
   scores are handled atomically. The claim is expected conformal risk control
   under exchangeability, not a distribution-shift guarantee.

The configuration schema is closed around these three stages. Perturbation
mechanism and strength are audit metadata, never model inputs.

The normative algorithm contract is
[`paper/CARE_DROID_FROZEN_SPEC.md`](paper/CARE_DROID_FROZEN_SPEC.md). The
experiment catalog and data-role details are in
[`config/experiments/tri_modal_robust/README.md`](config/experiments/tri_modal_robust/README.md).

## Data protocol

- Train, validation, and test remain package-group disjoint.
- CARE and all 13 baselines fit only on `expert_train` and select their
  checkpoint only on `expert_val`, the same deterministic 90/10 group split
  of train (`expert_split_seed=4242`).
- `routing_cal` and `decision_cal` use the immutable assignments in
  `labels/validation_roles_protocol_v3.json`.
- Baseline validation roles are audit-only, and every primary classification
  result uses the same unfitted binary argmax/softmax-0.5 rule.
- Test is used only for final reporting.
- Manifest vocabulary provenance must match the current train identities.

## AutoDL commands

Run from the project root:

```bash
# Check every formal job and runner without training.
python run.py paper_all --dry-run \
  --extra-config config/experiments/tri_modal_robust/_autodl_paths.yaml

# Primary seed 42.
python run.py final \
  --extra-config config/experiments/tri_modal_robust/_autodl_paths.yaml

# Remaining seeds after the primary seed-42 run.
python run.py seed_2024 seed_3407 \
  --extra-config config/experiments/tri_modal_robust/_autodl_paths.yaml

# All 13 registered comparison baselines (7 standard + 6 trusted-fusion).
python run.py baselines trusted_baselines \
  --extra-config config/experiments/tri_modal_robust/_autodl_paths.yaml

# Frozen CARE ablations.
python run.py paper_ablation \
  --extra-config config/experiments/tri_modal_robust/_autodl_paths.yaml
```

Existing outputs are rejected. Use `--overwrite` only when intentionally
replacing the same experiment. CARE ablations may reuse only a pipeline
generated by this frozen implementation and the same PT/Manifest lineage;
nonmatching checkpoints are rejected.
